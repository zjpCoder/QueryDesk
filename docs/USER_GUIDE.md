## 1. 安装、升级与首次启动

### 安装

1. 从 [GitHub Releases](https://github.com/zjpCoder/QueryDesk/releases) 下载 x64 安装程序。
2. 双击安装程序，选择目录，完成安装。
3. 使用桌面或开始菜单中的 QueryDesk 快捷方式启动。

程序自带 Electron 和 Java 运行环境，安装后可直接使用。Oracle 使用 JDBC Thin，不需要另外配置 Oracle Instant Client。数据库可以是本机或远程实例；远程连接需要本机网络可达。

### 升级

先处理当前标签未保存的表格修改和事务，再正常退出旧版。运行新安装程序，优先使用原安装目录。用户连接和工作区位于当前 Windows 用户的应用数据目录，程序文件与用户配置分开保存。

后台 MCP 进程也可能占用程序文件。遇到无法替换文件时，退出正在使用 QueryDesk MCP 的客户端后重试；不要在文件复制过程中反复启动旧版。

### 首次连接前准备

准备数据库类型、主机、端口、用户名、密码，以及 Oracle Service Name / SID 或 MySQL 数据库名称。需要 VPN、跳板或 SSH 隧道的环境，请先在系统侧建立网络通道。

## 2. 认识工作台

| 区域 | 作用 |
| --- | --- |
| 左侧数据源 | 保存连接、选择 Schema、搜索数据库对象 |
| 中间标签栏 | 在 SQL 控制台、表数据和 DDL 标签之间切换 |
| 中间工具栏 | 文件、执行、停止、事务、筛选和表格操作 |
| 下方结果区 | 查询结果、错误、分页及导出操作 |
| 右侧 AI | 配置模型、选择上下文、发送需求、查看建议 |
| 顶部与状态栏 | 主题、快捷键、Codex 接入、连接状态 |

每个 SQL / 表格标签使用独立数据库会话。切换标签时，确认标签对应连接、Schema、只读状态和提交模式，尤其是同时打开多个环境时。

## 3. 连接 MySQL 和 Oracle

### 新建连接

点击数据源标题旁的 `+`，或连接菜单中的新建入口。填写名称、分组、数据库类型和连接参数，测试成功后保存。连接名称建议包含环境或用途，例如 `本地开发 MySQL`。

### MySQL

| 项目 | 示例 | 说明 |
| --- | --- | --- |
| 主机 | `127.0.0.1` | 数据库服务器地址 |
| 端口 | `3306` | 以实际端口为准 |
| 数据库 | `demo` | 可按账号权限选择 |
| 用户名 | `demo_reader` | 使用自己的数据库账号 |
| 密码 | 在表单中填写 | 不写入 SQL 文本 |

需要 TLS 时启用对应选项；使用私有 CA 的服务器可指定 CA 文件。服务器证书必须通过验证。

### Oracle

| 项目 | 示例 | 说明 |
| --- | --- | --- |
| 主机 | `db.example.com` | 数据库服务器地址 |
| 端口 | `1521` | 监听器实际端口 |
| 连接模式 | Service Name 或 SID | 根据数据库配置选择 |
| Service Name / SID | `ORCL` | 示例值，不能代替实际配置 |
| 用户名 | `DEMO` | 数据库账号 |

Oracle 基于内置 Java 17 与 ojdbc8 驱动。连接设置中的 JDBC 检测入口可帮助检查运行时。Oracle 11gR2 是项目的主要兼容目标之一；具体数据库补丁、权限和网络配置仍影响连接结果。

### 环境和只读

连接可以标记为“开发”“测试”“生产”或“未标记”。标记会显示在连接和标签等位置，帮助区分环境。

“只读连接”会限制数据及结构变更。更改连接设置前先关闭该连接的全部标签，再重新连接，让设置应用到新会话。环境颜色本身不限制 SQL；数据库账号权限仍是最终权限边界。

### 连接和重连

点击已保存连接建立查询会话。程序恢复的 SQL 草稿初始没有数据库会话，需要点击“连接会话”。已连接标签可以使用“重新连接”。

重连保留 SQL 和所选提交模式，但不会恢复旧事务、结果游标或已丢失连接中的变更，也不会自动重放刚才执行的 SQL。

## 4. 对象搜索和表定义

选择 Schema 后，左侧按表、视图、序列、存储过程、函数、程序包和触发器分组。搜索框可按名称或说明缩小列表，`Ctrl+N` 打开对象搜索。

- 双击表或视图：打开数据浏览标签。
- 右键对象：选择打开数据、生成 SELECT、查看结构、编辑结构、导出或查看定义等可用操作。
- 点击“定位当前表”：在对象树中定位当前表标签对应的对象。
- 选中表后按 `Ctrl+B`：在 SQL 编辑器打开表定义。
- 在 SQL 编辑器中把光标放到表名，或选中表名，再按 `Ctrl+B`：尝试打开该对象的 DDL。

读取定义需要账号具备相应权限。复杂 SQL 中有歧义时，可在对象树直接选中对象，或明确使用 `Schema.表名`。

## 5. SQL 编辑、执行与文件

### 执行范围

`Ctrl+Enter` 执行所选 SQL；没有选区时执行光标所在语句。工具栏中的范围选项用于选择当前语句、选区或整个标签。Oracle PL/SQL 块按分句逻辑整体处理。

```sql
-- MySQL：只读连接测试
SELECT NOW() AS current_time;

-- Oracle：只读连接测试
SELECT SYSDATE AS CURRENT_TIME FROM DUAL;
```

执行多语句或写操作前，检查当前范围和连接。点击停止或按 `Ctrl+F2` 可以取消当前操作；取消不会自动重放语句。手动事务取消或失败后，根据会话提示先处理回滚。

### 参数绑定

使用命名参数，而不是手工拼接用户输入：

```sql
SELECT *
FROM demo_orders
WHERE id = :order_id;
```

执行时填写参数值。参数用于值，不能把表名、字段名或整个 WHERE 片段当作普通绑定参数。

### 补全与格式化

- `Ctrl+Space` 主动唤起补全。
- 方向键选择候选，`Tab` 或 `Enter` 接受。
- SQL 关键字按前缀匹配；标识符补全支持名称片段等匹配方式。
- 表和字段候选结合当前 Schema、FROM / JOIN 引用及别名生成。
- 模板可用 `Tab` 跳到下一个填写位置。
- `Ctrl+Alt+L` 格式化选区或全文。

补全不会执行 SQL。复杂 CTE、派生表、自定义语法的字段推导可能不完整，数据库负责最终语法验证。

### 查询错误

查询失败时查看错误文本和“定位错误”入口。程序会尽可能把数据库返回位置映射到编辑器；数据库没有返回精确位置时，可能定位到失败语句起点。编辑 SQL 或重新执行后旧标记会清除。

### SQL 文件和草稿

| 操作 | 快捷键 |
| --- | --- |
| 打开 SQL 文件 | `Ctrl+O` |
| 保存到原文件 | `Ctrl+S` |
| 另存为 | `Ctrl+Shift+S` |

支持 UTF-8 及带 BOM 的 UTF-8 / UTF-16，保存为 UTF-8。单文件限制为 4 MiB、100 万字符。发现磁盘文件已被外部修改或删除时，不会直接覆盖，可重新打开或另存。

编辑器内容也会自动保存为本地加密草稿。**草稿自动保存不等于写回原 SQL 文件。** 重启恢复 SQL 标签和文本，不恢复执行结果、数据库连接或未提交事务。

## 6. 数据筛选、排序和分页

### 添加筛选

双击表或视图，按以下顺序设置条件：

1. 选择“筛选字段”。
2. 选择包含、等于、不等于、大小比较、为空或非空。
3. 对需要值的条件输入“筛选值”。
4. 需要多个条件时点击“添加条件”。
5. 选择“全部满足（AND）”或“任一满足（OR）”。
6. 点击“应用”，或在筛选值中按 Enter。

最多支持 20 条条件，当前只有一层条件组。界面上的条件草稿只有应用后才生效；“条件已修改，尚未应用”表示当前表格仍使用旧条件。

“为空 / 非空”对应 SQL 的 NULL 判断，不需要填写值。在值输入框里输入字符串 `NULL` 不等于数据库 NULL。

### 排序字段和方向

在筛选区右侧选择“排序字段”，默认升序，点击旁边按钮切换为降序。清除字段选择可取消排序。改变排序会回到第一页，继续保留已应用条件。

列头右侧图标也可以按“升序 → 降序 → 取消排序”切换，并与排序字段控件同步。表数据浏览使用服务端排序，对全部匹配数据生效；SQL 查询结果表格的列头排序作用于已经加载的结果，不会重新执行原 SQL。

当前排序是单字段排序；需要多字段排序时，在 SQL 中编写 `ORDER BY column_a, column_b DESC`。

### 分页、刷新与复制字段名

表浏览每页 200 行，底部使用上一页 / 下一页。翻页、刷新和排序保留已应用条件。有未保存的表格草稿时，重新读取数据前需要确认处理。

点击列头名称复制完整字段名，包含被省略显示的部分。悬浮查看完整名称、字段类型和可获得的注释；排序操作使用旁边的独立图标。派生表达式、复杂查询或无法确认来源的列可能没有注释。

## 7. 表格修改与事务

### 新增、修改和删除

可编辑表中：

- 双击单元格修改值。
- 点击“新增行”，或 `Alt+Insert`，添加行草稿。
- 勾选行，点击“删除所选”，或 `Alt+Delete`，暂存删除。
- 焦点位于允许为空的单元格时，`Ctrl+Alt+N` 暂存设为 NULL。
- 点击“保存变更”，或在表格中按 `Ctrl+Enter`，检查并确认本批变更。

当前工具栏已移除“设为 NULL”“导出本页”“导出整表”按钮，保留相应快捷键或对象菜单中适用的入口。`Ctrl+Alt+Z` 撤销表格草稿并重新读取，必要时确认放弃变更。

编辑要求包括普通表、可用主键和适用的存储引擎 / 会话条件。视图、只读会话和无主键等情况可能只读，界面会显示原因。生成列、自增列或数据库自动维护列不适合普通直接编辑。

### 自动提交与手动事务

| 模式 | 保存后的状态 | 后续操作 |
| --- | --- | --- |
| 自动提交 | 已提交到数据库 | 不再属于待提交事务 |
| 手动提交 | 已写入当前会话事务 | 点击提交或回滚 |

表格草稿与数据库未提交事务是两个阶段：“保存变更”先把草稿写入当前会话；是否立刻提交取决于模式。查询标签之间使用独立会话，某标签的提交不会代替其他标签提交。

保存时会检查并发冲突。其他会话已改动同一行时，本批写入可能被拒绝；查看错误、核对数据库现状后处理，不要直接重复覆盖。

## 8. 表结构设计

在对象树中新建表，或右键已有表进入结构设计器。支持字段名、类型、可空性、默认值、注释、主键、普通 / 唯一索引和外键。

1. 修改设计内容。
2. 点击“预览 SQL”。
3. 检查目标 Schema、对象名称及每条语句。
4. 确认执行，查看逐条结果。

默认值使用 SQL 表达式，例如字符串需要写成 `'example'`，数字可用 `0`。执行前会检查结构指纹，防止用过期结构继续修改。

DDL 可能隐式提交，部分成功不能等同于整体回滚。发生部分失败后，重新打开设计器读取实际结构。重命名、分区、复杂类型、函数索引等高级操作使用 SQL 编辑器处理。

## 9. 导出 CSV / JSON

### 按筛选导出

先应用条件和排序，再点击“导出筛选结果”。导出使用已经应用的条件，不使用尚未应用的筛选草稿；读取全部匹配数据，而不只当前页。

### 整表导出

在左侧表或视图的右键菜单选择“导出整表…”，选择 CSV / JSON 和目标文件。整表导出忽略当前表浏览筛选条件。

### SQL 查询导出

结果区的“导出查询全部结果”保留产生该结果的 SQL、参数和 Schema，在独立只读会话重新执行。后来编辑器中的新文本不会替换原结果对应 SQL。

查询自身的 `LIMIT`、`ROWNUM` 等限制继续有效；不是无条件导出整张表。界面“导出已加载结果”则只导出当前已经读取的行。

### 进度和数据范围

导出显示进度并支持取消。独立导出会话只读取已提交数据，不包含其他标签未提交的修改或尚未保存的表格草稿；导出期间数据库变化也可能影响内容。

成功后使用界面入口查看文件。失败或取消时清理临时文件，原目标文件在成功替换前保留。异常退出遗留的 `.partial` 是未完成文件。大字段可能按客户端策略截断或使用占位文本，应查看相关提示。

## 10. AI 副驾驶

### 配置接口

打开右侧 AI 设置，填写：

| 项目 | 示例 |
| --- | --- |
| API 地址 | `https://api.example.com/v1` 或完整 `/v1/chat/completions` 地址 |
| 模型 | 服务商提供的实际模型标识 |
| 密钥 | 在设置表单中填写自己的密钥 |

使用支持 Chat Completions 的兼容服务。直接操作模式还需要工具调用能力；仅文本模型可选择生成、解释、修复或优化模式。外部模型的使用额度和费用由对应服务商决定。

### 直接操作

示例需求：

```text
查找包含“订单”注释的表，先列出候选。
查看当前 Schema 中订单表的核心字段。
按状态统计订单数量。
把指定表导出为 CSV。
```

模型可以搜索元数据、读取字段，并通过固定只读会话执行允许的查询。对象存在歧义时，先确认具体表名。写入和结构变更请求只生成未执行的 SQL 草稿，由用户检查后手动运行。

### 生成、解释、修复和优化

选择模式及 SQL 范围，可以发送选区、当前语句或全文。发送前查看实际范围；建议可以插入编辑器，或通过差异对比替换原范围。

编辑模型已经变化、切换目标标签等情况下，程序会拒绝用过期快照覆盖。优化建议应结合实际表结构、索引和执行计划判断。

### 上下文与发送预览

默认查询结果留在本机。可以选择附加表结构、错误或结果，使用“预览本次上下文”检查实际发送内容。超出限制的上下文会裁剪，预览中展示相应提示。

表名、字段注释、SQL 字面量、错误和结果都可能包含业务内容。数据库连接密码不作为模型上下文发送；主动附加的其他内容会发往配置的服务地址。

对话按连接与 Schema 隔离，运行期间保留。清空对话只清除当前对话，不会删除连接、SQL 文件或历史。

### AI 与 MCP 的区别

AI 面板的直接数据库查询采用专门的只读工具边界。Codex MCP 则另外提供 SQL 执行、事务、数据写入和 DDL 工具，不能把 AI 面板的只读说明套用到所有 MCP 调用。配置步骤见 [MCP 文档](MCP.md)。

## 11. 主题和快捷键

顶部主题菜单提供经典紫、清透紫和香槟金。主题设置在本机保存，编辑器、表格和弹窗随之更新。

右上角“快捷键”可按名称、区域或键位搜索。常用操作：

| 区域 | 快捷键 | 用途 |
| --- | --- | --- |
| 编辑器 | `Ctrl+F` / `Ctrl+R` | 查找 / 替换 |
| 编辑器 | `Ctrl+D` / `Ctrl+Y` | 复制当前行或选区 / 删除行 |
| 编辑器 | `Ctrl+/` / `Ctrl+Shift+/` | 行注释 / 块注释 |
| 编辑器 | `Ctrl+G` | 跳转行 |
| 工作区 | `Ctrl+Shift+F` | 搜索工作区 SQL 文本 |
| 工作区 | `Ctrl+Shift+A` | 查找已支持的操作 |
| 工作区 | `Ctrl+E` | 最近使用的已打开标签 |
| 工作区 | `Ctrl+Alt+E` | 查询历史 |
| 工作区 | `Ctrl+Shift+F10` | 当前连接新建控制台 |
| 标签 | `Ctrl+F4` | 关闭标签 |
| 标签 | `Ctrl+Tab` / `Ctrl+Shift+Tab` | 循环切换标签 |
| 表格 | `Ctrl+F` | 查找已加载单元格 |

快捷键按焦点处理。AI 输入框、弹窗和正在编辑的单元格可能优先处理输入；输入法占用 `Ctrl+Space` 时，调整系统热键后再使用主动补全。

## 12. 本地保存与常见问题

### 文件放在哪里

| 内容 | 位置 / 行为 |
| --- | --- |
| 连接和模型设置 | `%APPDATA%\querydesk\settings.json`，敏感字段由 safeStorage 加密 |
| SQL 工作区 | `%APPDATA%\querydesk\workspace.enc`，加密草稿 |
| SQL 文件 | 用户打开或保存时选择的路径 |
| 手动导出 | 用户选择的目标路径 |
| AI 自动导出 | Windows 下载目录中的 QueryDesk 子目录 |

最近查询历史保存在本机，SQL 文本可能包含字面值。备份和迁移时保护用户配置；跨 Windows 用户复制加密配置不等于能在另一账号下解密。

### 连接失败

先检查网络 / VPN、主机端口、Service Name 或 SID、用户名密码和账号权限。能访问服务器不代表指定数据库服务或 Schema 一定可用。Oracle 可使用 JDBC 检测入口检查运行环境。

### 表无法编辑

查看界面的只读原因；检查是否为只读连接、视图、无主键表或不满足编辑条件的表。不要把只读显示误认为连接失败。

### 筛选输入了却没有变化

点击“应用”。条件草稿与已经应用的条件分开；导出、翻页、刷新和排序使用已应用条件。

### 为什么排序好像只影响了一部分结果

区分表浏览和 SQL 查询结果。表浏览使用服务端排序；SQL 结果列头默认只排列已加载行。需要数据库全量排序时，在 SQL 中明确写 `ORDER BY` 后重新执行。

### AI 接口报错

检查地址是否指向兼容 Chat Completions 的接口、模型名称是否准确、密钥和余额是否有效；限流时按提示稍后重试。不支持工具调用的模型改用建议模式，或选择支持工具的模型。

### 退出后事务是否恢复

不会。恢复的是 SQL 草稿和标签信息。数据库会话及未提交事务不能作为本地文档恢复；处理事务后再退出。

### 如何反馈问题

在 [Issues](https://github.com/zjpCoder/QueryDesk/issues) 提供应用版本、Windows 版本、数据库类型和版本、复现步骤、预期及实际结果。必要时附经过脱敏的 SQL、错误文本或截图，不附账号密码、密钥或真实业务导出。
