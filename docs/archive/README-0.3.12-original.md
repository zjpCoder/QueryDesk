# QueryDesk 0.3.12 · Windows AI 操作助手预览版

面向日常开发的数据库工作台：MySQL、Oracle 11gR2、SQL 多标签编辑、表格数据编辑、可视化建表改表和 AI SQL 副驾驶。中文界面，支持深浅主题，无需产品账号。



## 0.3.12 AI 能力增强

AI 上下文现在有明确大小保护：SQL、错误、表结构和结果行会按安全上限裁剪，发送预览会显示被裁剪的部分，避免模型接口因内容过大失败。结果行默认最多保留 20 行用于上下文；查询和导出结果仍默认留在本机。

模型网络错误、超时、HTTP 400/401/403/404/408/413/429/5xx、Retry-After 限流提示均转换为中文可操作提示。工具调用结果也有大小上限，避免表结构返回过大拖垮后续轮次。找表返回多个候选时会提示用户确认，模型不能把歧义对象直接当成确定表。

AI 操作对话按连接和 Schema 隔离，并新增“清空对话”按钮；清空只删除当前连接 / Schema 的运行期对话，不影响 SQL、数据库连接、密钥或查询历史。

## SQL 草稿、文件与重连

SQL 标签的文本、所属连接、Schema、顺序、当前标签及提交模式会自动保存到当前用户目录的 `workspace.enc`，使用 Windows safeStorage 加密。停止输入约 0.7 秒后保存，正常退出时再次刷新草稿；保存异常会持续显示提示。重启后仅恢复 SQL 标签，不恢复数据库会话、结果、表格草稿或未提交事务，也不自动执行 SQL。仅当前标签初始化编辑器，其他恢复标签首次切换后再加载。

“打开 SQL / 保存 SQL / 另存为”对应 `Ctrl+O / Ctrl+S / Ctrl+Shift+S`。打开文件使用当前连接；没有当前标签时使用第一个已保存连接，打开后处于未连接状态。支持 UTF-8、带 BOM 的 UTF-8/UTF-16，保存统一为 UTF-8。单文件最多 4 MiB、100 万字符；文件被外部修改或删除时拒绝覆盖，可另存其他文件或重新打开核对。SQL 草稿自动保存不等于写回原 `.sql` 文件，文件标签有修改标记。关闭修改过的标签会确认移除草稿；退出应用时可保留草稿下次继续。

SQL 草稿最多 100 个标签、整体 20 MiB（包含文件保存基线）；超过限制会明确报错，不覆盖上一次成功保存的草稿。工作区文件损坏或草稿对应连接已不存在时保留原文件，暂停自动覆盖，不静默重置。草稿无法读取时仍可将重要 SQL 另存为文件。

恢复标签点击“连接会话”，已连接标签可点击“重新连接”。保留 SQL、Schema 和自动/手动提交模式，清空旧结果；有未处理事务或表格草稿时须先确认放弃。AI 只读标签重连后仍只读。程序不会自动重放语句，也不会声称原事务已经恢复。同一用户配置目录只运行一个应用实例，重复启动会聚焦原窗口。

## 普通界面整表导出

表/视图右键“导出整表…”或数据浏览器“导出整表”，选择 CSV/JSON 和保存位置，显示已写入行数并支持取消。复用流式导出能力，不受界面 10,000 行上限限制，使用独立只读会话，不影响当前标签事务。此入口导出整表已提交数据，不包含当前筛选条件、未提交事务或表格草稿；原“导出本页”和“导出已加载结果”继续可用。

成功后显示文件路径、行数和打开文件夹入口；取消/失败删除临时文件，已存在的目标文件在成功前保持原样。大字段仍使用既有占位/截断策略并给出提示。异常退出可能留下带随机名称的 `.partial` 未完成文件。

## SQL 智能补全

输入 `selec` 优先提示 `SELECT`，关键字按前缀匹配；`FROM` / `JOIN` / `UPDATE` / `INTO` 后提示表与视图，字段位置结合当前语句中的表和别名提示。支持 `SELECT c. FROM customers c`、限定 Schema 与普通 JOIN；多个表的字段候选会带别名插入。字段注释与类型显示在候选说明中，字符串和注释内不自动补全。

使用 `Ctrl + Space` 主动唤起，方向键选择，`Tab` 或 `Enter` 接受。查询、限量查询、插入、更新和删除模板可按 `Tab` 逐项填写；MySQL 使用 `LIMIT`，Oracle 11g 使用 `ROWNUM`。模板和补全只修改编辑器文本，不会自动执行 SQL。更改与删除模板需要填写实际条件。

字段结构仅针对当前语句引用的已知表按需读取，每次最多 4 张表，单编辑器缓存最多 24 张表；切换会话/Schema 或刷新对象清除缓存。失败时仍提供关键字，可刷新对象后重试。现阶段使用轻量上下文分析，复杂 CTE、相关子查询、派生表、同义词及数据库自定义语法不保证完整字段推导；不是 DataGrip 级静态分析。

执行前对悬空 `FROM`、`WHERE`、`SET` 等常见未完成片段给出提示，可继续编辑或选择仍然执行；不要求结束分号，PL/SQL 沿用原有整体执行逻辑。数据库仍负责最终语法检查。

## 内存使用

0.3.5 将 SQL 编辑器、数据表格和 SQL 格式化器改为首次使用时加载，欢迎页不初始化这些运行时。SQL 定义与 AI 差异弹窗关闭后销毁编辑器；字段补全仅为当前编辑器生成候选，避免多标签重复生成。已显示的查询行由界面持有，后台只保留尚未读取的分页；AI 初始结果在交给查询标签后释放额外引用。

打开的标签仍保留 SQL、结果与未提交变更；可关闭不再需要的标签释放这些资源。Electron 使用多个隔离进程，已释放的对象何时归还操作系统由运行时决定，内存不会保证立即回到刚启动时的数值。Oracle 的 Java 工作进程仍按需启动，首次使用编辑器/表格会有一次加载过程。

## 运行与连接

本次采用直接更新已安装目录的方式交付，不重新生成安装包。目标系统为 Windows 10/11 x64。此内部预览版未做代码签名，也不提供自动更新。更新后的程序自带 Electron 和 Java 运行时，无需安装 Node.js、Java 或 Oracle Instant Client。升级前关闭旧版程序；原有连接配置和加密密码继续使用，旧客户端目录字段会被忽略。

1. 点击“新建数据库连接”，填写类型、主机、端口及账号密码，测试后保存。
2. 点击左侧连接建立查询会话。MySQL 可在连接后选择默认数据库；Oracle 可填写 Service Name 或 SID。
3. 每个查询标签和表数据标签使用独立会话。自动提交默认开启；关闭后，通过工具栏的勾号提交、回退图标回滚。
4. 左侧对象按表、视图、序列、存储过程、函数、程序包、触发器分类，显示数量并支持展开/收起，空组隐藏，搜索自动展开匹配分组。双击表或视图打开数据。对象右侧菜单可查看结构、修改表结构或查看程序对象定义。

Oracle 使用 **JDBC Thin / ojdbc8 19.25.0.0 + Eclipse Temurin Java 17.0.20.1 x64**。在连接表单填写主机、端口、Service Name 或 SID、账号及密码即可；“JDBC 驱动”页可检测内置运行环境。已用真实 Oracle 11.2.0.4 验证 Service Name 连接；11.1 和其他旧补丁版本不在默认兼容承诺内。

所有 Oracle 连接共用一个按需启动的 Java 工作进程，每个标签仍使用独立 JDBC 会话。Java 初始堆 16 MiB、最大堆 256 MiB；该上限不包括线程、类和其他进程内存。关闭应用后 Java 自动退出。MySQL 继续使用 mysql2。凭据通过私有进程管道传递，不出现在 Java 命令行中，也不监听本机端口。网络读取超时为 5 分钟，超时后不会重放操作。

首版支持直连；需要 VPN 或隧道时由系统提供。MySQL TLS 启用后验证服务器证书，可指定 CA 文件。不提供跳过证书校验开关。

## 查询、结果和事务

查询标签采用圆角布局，显示查询名称和所属连接，选中项使用边框与底色区分。长名称省略显示，悬浮可查看完整名称和 Schema；标签过多时使用右侧省略菜单切换，关闭按钮和未提交提示保持可见。

执行成功后，在本次 SQL 起始行的行号右侧显示绿色对号。支持当前语句、选区、完整脚本及 AI 已执行查询；修改内容或重新执行时清除旧标记，执行期间修改过的内容不标记，失败或取消不显示对号。脚本只有全部成功才统一标记各语句，部分成功仍以结果区为准。对号表示执行成功，不代表手动事务已经提交；悬浮可查看状态。

- `Ctrl + Enter` 执行选区，无选区时执行光标所在语句。“执行脚本”按顺序执行普通多语句，失败后停止，保留已成功语句的结果。
- Oracle 匿名块、过程、函数、触发器、包等保留内部的分号，多块脚本用单独一行 `/` 分隔。MySQL 存储过程脚本支持 `DELIMITER`。这不是完整 SQL*Plus 或 mysql 命令行解释器。
- 使用 `:name` 形式输入参数，执行前弹窗填值；`NULL` 按钮表示真正的数据库空值。MySQL 通过驱动预编译绑定参数，Oracle 使用原生绑定。
- 查询结果默认加载 200 行，可继续加载，单个结果集保留最多 10,000 行，单次脚本结果缓存最多 32 MiB；“导出已加载结果”只包含已经加载的行，也可使用“导出查询全部结果”重新查询并导出。Oracle 使用结果游标；MySQL 流式消费结果并只缓存前 10,000 行，因此超大 MySQL 查询仍可能消耗较长网络时间，建议在 SQL 中明确限制范围。
- 大整数和精确数值保留字符串，避免 JavaScript 数值舍入。单元格文本超过 64 KiB 标记截断；二进制和 LOB 显示提示，可通过 SQL 截取查看。日期按数据库会话格式显示。
- SQL 查询结果只读；表数据浏览器提供服务器端筛选、排序和每页 200 行的翻页。无主键、视图以及含大字段/二进制/复杂类型的表在首版只读。
- 表数据编辑需要主键；MySQL 仅开放 InnoDB 表编辑，其他存储引擎只读。双击普通单元格编辑，支持新增行、删除所选、设为 NULL 和批量保存。新增行未填写的字段使用数据库默认值；空字符串与 NULL 分开处理。
- 保存前使用主键及完整原始行进行并发校验。冲突会回滚本批修改；手动事务中的其他修改通过保存点保留。生成列、自增列及自动维护列不允许直接编辑。
- 取消查询不重放 SQL。取消或异常后，手动事务可能要求先回滚。关闭存在未提交事务或表格草稿的标签会提示；已自动提交的修改不能通过关闭撤销。
- SQL 编辑器文本自动保存到恢复草稿；AI 对话不跨应用重启保存。最近 100 条执行历史保存在本机。查询历史包含 SQL 字面值，不包含完整结果集。

表和字段悬浮显示注释、完整名称及字段类型。表右键支持打开数据、生成 SELECT、查看结构、添加列、修改表结构、添加索引、复制名称和刷新；字段右键支持修改列、删除列、添加索引、复制或插入列名。所有结构操作先进入设计器，再预览 SQL 并确认执行。

## 结构设计器

支持字段名称、类型表达式（如 `VARCHAR(200)`、`NUMBER(18,2)`）、可空性、默认值、注释、主键、普通/唯一索引及外键。Oracle 唯一索引会同时创建可被外键引用的唯一约束。首版默认值使用 SQL 表达式，字符串需要单引号。

修改结构前先预览 SQL。实际执行使用独立连接，重新检查结构指纹，结构过期则拒绝执行。新建 MySQL 表使用 InnoDB。DDL 可能隐式提交；逐条记录成功或失败，部分成功后不会伪装为整体回滚。发生部分失败时关闭并重新打开设计器，以实际结构为准。手写过程中的 COMMIT 或动态 DDL 遵循数据库自身语义，客户端不能撤销已提交的修改。

现有字段/表的重命名、生成表达式、自增配置、分区、函数索引、特殊类型和高级约束通过 SQL 编辑器处理。设计器不会自动迁移或猜测这些属性。

保存变更会先结束当前单元格编辑，再展示确认框。成功后持续显示已提交或待提交事务的状态；冲突与错误保留草稿。

## AI SQL 副驾驶

点击 AI 设置，填写 **API 根地址或完整接口地址、模型名称、API 密钥**。根地址 `https://服务商地址/v1` 和完整的 `/v1/chat/completions` 均可，不会重复追加路径。本机兼容服务可以使用 HTTP。直接操作模式要求模型支持 Chat Completions 的 `tools/tool_calls`；不支持时可切换为生成 SQL、解释、修复或优化模式。

默认“直接操作应用”：输入“查询商户表”并点击“发送并执行”，AI 按表名/中文注释搜索元数据、读取字段并执行只读查询，自动打开带结果的新标签。输入“导出某表为 CSV/JSON”会流式导出整表到 Windows 下载目录的 QueryDesk 子目录，自动生成唯一文件名并显示行数及“打开所在文件夹”按钮。整表导出不受查询界面的 10,000 行显示上限限制；大字段仍使用占位或截断文本，遇到此类值会提示。导出失败会删除临时文件；应用异常终止遗留的 `.partial` 是未完成文件。

自动查询使用独立、固定只读的数据库会话，不提交其他标签的事务。SQL 经过单语句、只读语法及函数限制，并启用数据库只读事务。写入、删表等请求只打开未执行的 SQL 草稿，由用户检查并点击运行。工具不提供系统命令、任意文件路径、切换连接或密钥访问。表名有歧义时模型应先询问；每次最多 8 轮工具调用，超时 3 分钟，可点击停止。已完成的结果与文件会保留。

模型可以按需读取当前 Schema 的表名、注释、字段及工具状态；**查询/导出的结果行默认留在本机**。直接模式默认不附加编辑器 SQL。勾选结果行或错误后会展示发送预览，最多附加 50 行；也可主动点击“预览本次上下文”。SQL、错误与注释可能含数据值，数据库凭据不会进入模型请求。对话摘要按连接与 Schema 隔离，只在应用运行期间保留。

AI 输出支持 Markdown 标题、粗体、行内代码、列表、表格、引用和代码块；HTML 不执行，外部图片不加载，链接仅作为文字展示。

生成、解释、修复和优化模式继续只提供建议，发送前可预览，输出可插入或对比替换编辑器，不自动执行。优化建议需结合执行计划验证。外部模型使用 HTTPS，密钥在 Windows 本机加密存储；模型费用由服务商收取。

查找/替换栏按钮使用原生悬浮提示，避免提示框被编辑区裁切或覆盖关闭按钮；Escape 和关闭按钮均可正常关闭查找栏。

## 0.3.11 查询、筛选、导出与 AI 选区

- **错误定位**：执行错误显示红色标记和“定位错误”入口。将数据库返回的位置映射到原 SQL 标签，支持当前语句、执行选区和多语句脚本；Oracle PL/SQL 的中文 / 英文行列信息及参数占位符替换也参与映射。MySQL 只返回行号时标记整行，未返回位置时明确定位失败语句起点。编辑文本、重新执行或取消会清除旧标记；执行期间修改过文本则不添加过期位置。
- **多条件筛选**：数据浏览器可添加最多 20 个条件，选择全部满足（AND）或任一满足（OR），支持等于、不等于、大小比较、包含及 NULL。当前版本为一层条件组，不支持嵌套组合。点击“应用”才改变当前结果；翻页、刷新和排序保留已应用条件。有未保存表格变更时仍需确认放弃。
- **按筛选导出**：点击“导出筛选结果”，使用已经应用的条件和排序导出全部匹配行。尚未应用的条件草稿不参与导出；“导出整表”继续忽略筛选。
- **完整查询导出**：结果区的“导出查询全部结果”保留产生该结果的 SQL、参数及 Schema，选择 CSV / JSON 和保存位置，流式导出超过 10,000 行的数据。编辑器后来修改的 SQL 不会替换原查询。SQL 自带的 LIMIT / ROWNUM 等限制保持有效。
- 导出会在独立只读会话重新执行查询，只读取已提交数据；数据可能与原结果不同，不包含当前标签未提交的写入。支持单条 SELECT / WITH 和常用函数，拒绝写入、多语句、锁定读取、序列递增、文件操作和未允许的自定义函数；不是任意脚本重放。导出可取消，失败或取消清理临时文件并保留原目标。大字段截断 / 占位规则与原导出一致。
- **AI SQL 范围**：建议模式新增“选区优先，否则当前语句”“仅选中 SQL”“当前语句”“当前标签全文”。发送预览显示实际范围；直接操作模式继续默认不附加编辑器 SQL。局部解释和修复只发送相应 SQL 文本，结构、错误与结果行沿用原附加选项。
- **AI 局部替换**：差异框展示发送时的原文与建议，只替换该范围，保留相邻语句，可用 Ctrl+Z 一次撤销。切换到别的标签或原编辑模型发生变化后拒绝覆盖；即使撤销回相同文字，也需重新发送以获得新快照。生成结果不会因替换操作自动执行。

## DataGrip Windows 常用键位

右上角“快捷键”可查看完整已支持列表。采用 Windows 默认键位，不导入自定义 keymap，也不绑定尚未实现的 DataGrip 功能。

- SQL：Ctrl+Enter 执行选区/当前语句，Ctrl+F2 停止，Ctrl+Alt+L 格式化选区/全文。
- 编辑：Ctrl+/ 行注释，Ctrl+Shift+/ 块注释，Ctrl+Space 补全，Ctrl+F 查找，Ctrl+R 替换，Ctrl+D 复制选区/行，Ctrl+Y 删除行，Ctrl+W / Ctrl+Shift+W 扩大/缩小选区，Ctrl+Shift+Z 重做，Ctrl+G 跳转行。
- 表格：Ctrl+Enter 保存变更（确认后写入），Alt+Insert 新增，Alt+Delete 暂存删除所选，Ctrl+Alt+N 设为 NULL，Ctrl+Alt+Z 撤销草稿并刷新（需确认），Ctrl+Alt+上/下箭头翻页，Ctrl+F5 刷新。
- 对象树：Ctrl+F5 刷新，选中对象后 F4 打开数据/定义，Ctrl+F6 修改表结构。
- 标签：Ctrl+F4 关闭，Alt+左/右箭头或 Ctrl+Tab / Ctrl+Shift+Tab 切换。Ctrl+Tab 为顺序循环，不实现 DataGrip 最近使用切换器。

## 从源码开发

需要 Node.js 22.12+ 或 24、JDK 17 或 21（用于编译），Windows x64。首次准备运行时需联网，从固定官方地址下载并核对 SHA256；终端用户安装成品无需任何开发环境。

```powershell
npm ci
npm run setup:jdbc
npm run dev
npm test
npm run build
npm run smoke
npm run dist
```

安装包位于 `release/`，解包程序位于 `release/win-unpacked/`。`npm run smoke` 启动独立测试配置的 Electron 程序和本地 MySQL/AI 协议夹具，不读取个人数据库连接；输出截图和报告到项目外的 `work/`。该测试证明程序链路可用，不能替代真实数据库的兼容性验收。

连接和 AI 密钥保存在 `%APPDATA%/querydesk/settings.json` 的加密字段中，由当前 Windows 用户的 `safeStorage` 保护。配置损坏时程序会报错并保留原文件，不自动清空覆盖。修改连接配置前必须先关闭该连接的全部标签。

前期直接更新文件，避免反复安装。正常退出 QueryDesk 后，在项目根目录执行：

```powershell
npm run pack
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/update-installed.ps1 -InstallDirectory 'D:\Program Files\db-tool\QueryDesk'
```

`pack` 只生成可运行目录。更新脚本备份并校验有变化的程序文件，不改动用户配置；程序仍在运行时拒绝更新，不强制结束进程。默认备份在项目外的 `work/installed-backups/`，包含原文件和 `update.json` 清单。更新期间复制失败会恢复已改动文件。脚本用于 Electron 运行时未变化的增量更新；更换 Electron 版本时需完整目录升级。Windows 已安装应用列表中的版本信息可能仍显示原安装包版本，应用内部版本以当前文件为准。
